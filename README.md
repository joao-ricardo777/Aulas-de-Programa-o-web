# Aula de Desenvolvimento Frontend

Este repositório foi criado com o objetivo de acompanhar minha evolução nos estudos de **desenvolvimento frontend**.

Durante as aulas, aprendi e pratiquei diversos conceitos fundamentais de HTML e CSS, registrando anotações e exemplos práticos para fixação do conteúdo.

## 📚 Conteúdos aprendidos

### HTML

- Estrutura básica de uma página (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Tags de título (`<h1>` até `<h6>`)
- Parágrafos (`<p>`)
- Quebra de linha (`<br>`)
- Links (`<a href="">`)
- Listas ordenadas e não ordenadas (`<ol>`, `<ul>`, `<li>`)
- Tabelas (`<table>`, `<tr>`, `<td>`, `<th>`)
- Formulários (`<form>`, `method`, `action`)
- Inputs:
  - Texto
  - Senha
  - Email
  - Número
  - Campo de busca
- Uso de `<div>` como container genérico
- Atributos como `class` e `id`

### CSS

**Seletores:**
- Por tag (`h1`, `p`)
- Por classe (`.classe`)
- Por ID (`#id`)

**Estilização de texto:**
- `color`
- `font-size`
- `font-family`
- `text-align`
- `text-decoration`
- `text-transform`

**Box Model:**
- `margin`
- `padding`

**Outros conceitos:**
- Layout básico com containers (`div`)
- Organização visual de páginas (menu, corpo e rodapé)

## 🎯 Objetivo

Este repositório serve como:

- Registro do meu aprendizado.
- Base para futuros projetos.
- Referência rápida dos conceitos iniciais de frontend.

---

**Tecnologias estudadas:** HTML5 e CSS3.
